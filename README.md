# Daniela Moraes — Micropigmentação & Estética

Landing page estática da marca Daniela Moraes, com HTML, CSS e JavaScript nativos.

## Desenvolvimento

Sirva a pasta raiz com um servidor estático e abra `index.html`. Os arquivos de imagem e vídeo usados pela página ficam em `assets/imagens/`.

## Deploy

O projeto não requer etapa de build nem instalação de dependências. A raiz do repositório contém `index.html`.
